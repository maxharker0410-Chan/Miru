# S.Chat 沙盒核心 v1.1

本次依作者提供的 v1.1 平台設定書更新共通引擎。魔法異世界保留原 153 名角色、195 張圖片、77 個場景、穩定 ID、獨立記憶與同行狀態。新增的《黑幕之城》定位不會強制套成所有故事的預設主線；本次不憑空補出尚未提供的 36 人完整設定。

## 玩家操作

- 故事工具 → 自訂開局：填公開背景、專長、開場事件及多項秘密，逐項指定知情 NPC；未選知情者表示玩家自己保密。每次建立獨立新紀錄，舊進度保留。
- 動作使用 `*放下文件*`，說話使用 `「你先看看。」`，可交錯；原 `**動作**` 繼續支援。未標記文字仍依語意判讀。動作是意圖，不保證成功。
- 「繼續」只推進一回合，說話者 ID 去重；明確空名單可保持沉默。導演與角色必須在玩家需要決定時交回控制權。
- 明確等待如「等待 1 小時」「我等一個小時」依單一世界時鐘處理。一般情境的模型估時上限 600 秒，緊急情境上限 30 秒；不是固定每回合扣同一時間。
- 已啟動的相關行動會在離場後保留期限。公開期限或影響玩家的行動可中斷等待；私人一般調查不直接揭露給玩家。到期先進入待判定，不把時間到當作必然成功。
- 暫停與繼續遊玩不會變成劇中台詞。閱讀面板、真實打字時間及關機時間不推進遊戲時間。舊存檔首次升級從新時鐘零點開始，不捏造過去經過幾天。
- 玩家死亡後不能再送一般回合，可讀先前存檔或重開。已死亡 NPC 會退出活人名單；死亡不自動交接權力。此版尚無通用復活操作，需故事特有事件另作擴充。

## 記憶與資訊

服務端分開保存個人記憶、帶來源／時間／確定度的信念、客觀死亡事件、重要事件紀錄，以及已啟動的事項。傳言、懷疑或誤信不自動變成客觀真相。角色只收到自己的私有內容、授權背景及親歷對話；不把別人的記憶加入其請求。

關係分開記錄信任、親近感情、尊重、畏懼、利益與立場六個方向；更新需本回合證據，每次限幅，不代表必然服從。AI 仍負責敘事與合理性判斷，系統負責 ID、時鐘、來源、結算順序與持久化；不是完整的人類心理或定量戰鬥模擬。

玩家面板不再回傳全部 NPC 私人記憶、關係分數或私下計畫。作者編輯模式仍能讀取自己提供的設定，並非對作品作者隱藏其原稿。

## 存讀檔

介面提供八欄。每欄保存完整遊玩狀態與當時故事定義；讀檔產生新分支，原進度與其他欄位保留。角色知情、記憶、世界時間、物品、事件、在場名單、同行及進行中的情境一併恢復。圖片更新不刪舊素材，因此舊時點仍能用原圖片。

後續安裝新的 DLC 可加入讀檔分支，保留該分支的歷史定義。存檔版本目前為 1，其他不支援版本會拒絕讀入，避免靜默破壞。

## 動態人物與素材

導演可在有來源、工作和動機的現場加入新 NPC，每回合上限 3 人、每分支上限 200 人；系統配置永久 ID，不重用素材名稱當 ID。作者名冊不限制新居民出現。

人物初期可無圖，仍能說話與累積獨立記憶。「人物與情報」可替這個 ID 補圖，不更換其身分。缺圖回退至同一人的既有素材或文字，不借別人圖片。新的圖片綁定隨存檔分支保存。

## Word 草稿及三類 ZIP

「用設定書建立故事」可上傳 Word 或貼文字，沿用目前模型整理成可編輯草稿。先檢查，再按儲存建立獨立故事；原故事不會被草稿覆蓋。原魔法異世界雙 ZIP 與七區 Word 更新入口仍保留。

通用 ZIP 需有 `schat-package.json`；打包工具或作者整理流程產生，不要求玩家逐張操作。欄位為 `schema_version:1`、`type:story/assets/dlc`、穩定的 `package_id` 與 `version`。素材與 DLC 另指定 `target_story_id`；完整包使用 `story`，DLC 只新增 `characters` 與 `scenes`，不覆寫舊 ID。

`bindings` 每筆包含 `kind:character/scene`、`id`、`path`、`sha256`。圖片原樣保存，檢查格式、尺寸、路徑與雜湊。相同資料包重送去重；同一包 ID 換成其他內容會拒絕，需明確版本遷移。包內程式永不執行。

DLC `events` 支援 `enter_scene` 與 `after_seconds`，各事件具有唯一 ID。`retroactive:false`（預設）從此分支安裝時點計時，不回補安裝前事件；`true` 可核對已到期時間或目前進入地點。事件一旦觸發便保留記號，不因重試重播。更複雜的任務圖、條件運算和版本衝突合併仍屬設定書第 13 節的後續細化。

## 儲存庫清理

本分支移除 516 個舊 Miru 檔案，約 55 MB，另以 S.Chat 專用打包規格取代原規格。移除範圍是 Live2D／桌面寵物、截圖感測、舊 Android/Tauri 外殼、舊展示頁、舊維運部署工具及相應測試文件。原登入編碼、使用者隔離、聊天設定與桌面資料路徑相容層保留，Apache-2.0 與原來源歸屬保留。

Git 歷史與舊分支沒有改寫。這些刪除只有進入此分支／PR，沒有刪除使用者本機資料，沒有直接合併到主分支或部署正式 Vercel／Supabase。

## 驗證

Python 回歸涵蓋原故事、雙 ZIP、Word、角色隱私與新增狀態機；前端 Node 驗證分頁、對話與完整文字。測試總數以本次 S.Chat 專用套件為準，舊 Miru 功能測試隨對應功能移除。

另在隔離副本驗證：原聊天模型回覆、自然語言圖書館換場、同行、存讀檔、153 人與全部 195 張圖片讀取；Windows 實際 EXE 與本機 API；手機 844×390、390×844 及桌面尺寸畫面、介面存讀檔與情報面板。

實體手機鍵盤、PWA 安裝與長篇遊玩仍由實機驗收；長期性格演變、完整家庭／勢力網路、定量能力與資源結算、通用復活及複雜 DLC 遷移尚未宣稱完成。這次是可測試的共通核心，不是整座城市所有居民的持續離線模擬。
