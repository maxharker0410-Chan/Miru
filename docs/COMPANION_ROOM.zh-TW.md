# Companion V1 房間模式

Windows 圖片角色顯示、眨眼、聊天姿勢、重開後位置保存：使用者已於 2026-09-22 回報正常。

## 操作

點角色展開工具列，按「房間」。房間使用內建紫髮圖片角色，點下方地板即可平移到指定位置。
上方提供回桌面、回中央、休息／喚醒及聊天入口。休息時停止移動；喚醒後恢復待機。
房間的落點會保存，回到桌面則恢復原本的桌寵位置與大小。

房間目前在現有桌寵視窗中顯示。角色保留同一組八張原圖，以平移呈現移動，沒有步行骨架或聲音嘴型同步。
聊天、情緒及記憶沿用 Miru 已設定的服務，不新增 API 帳號，也不代表 ChatGPT Plus 可供 API 使用。

## Windows 驗收

- 進出房間後，透明桌面與原位置恢復。
- 點地板、連續改目的地、回中央，人物不離開可移動範圍。
- 移動中休息停止，喚醒可再次移動。
- 房間聊天可輸入，等待與回覆姿勢正常。
- 重開並再次進房間，落點保留。
