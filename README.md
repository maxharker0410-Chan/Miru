# S.Chat

可載入獨立故事世界的角色扮演沙盒，支援 Windows 與手機 PWA。沿用原邀請碼、聊天模型設定及既有故事資料，每名角色維持自己的記憶與知情範圍。

- 自訂故事、Word／文字轉可編輯草稿，以及魔法異世界雙 ZIP 匯入。
- 手機橫向與直向舞台、背景換場、多人立繪、底部對話與自由輸入。
- `*放下文件*「你先看看。」`；舊 `**動作**` 也可使用。
- 共通規則 v1.1：單一遊戲時鐘、等待中斷、角色認知與多面向關係、具期限的 NPC 行動、死亡後果及動態 NPC。
- 八個手動存檔欄位；讀檔建立獨立分支，完整保留目前進度。
- 地圖、物品、事件及人物情報獨立面板，只呈現玩家已知的資訊。
- 素材包與 DLC 延續既有世界；使用固定 ID，禁止直接覆寫已發生的歷史。

請見 [v1.1 功能與驗證範圍](docs/S_CHAT_SANDBOX_V1_1.md)、[匯入說明](docs/S_CHAT_WORLD_IMPORT.md) 及 [建置方式](docs/BUILDING.md)。

這個分支已整理成 S.Chat 專用，移除舊 Miru 的桌面伴侶、截圖感測、原生 Android／Tauri 外殼與相關展示。保留舊資料目錄名稱及邀請碼格式，是為了直接讀取原有帳號與遊玩資料；不會刪除使用者資料。

本專案衍生自 Miru，保留原 Apache-2.0 授權與第三方聲明。正式服務不會因草稿 PR 自動更新。
